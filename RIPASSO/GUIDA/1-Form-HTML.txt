1 - MODULI (FORM) HTML
======================

SCHEMA BASE
-----------
<form action="pagina.php" method="get">
    Nome: <input type="text" name="nome">
    <input type="submit" value="Invia">
</form>

  action  = a quale file PHP vanno i dati
            (action="" oppure niente = la pagina stessa)
  method  = get (default) oppure post
  name    = il NOME con cui il dato arriva a PHP.
            Senza name il campo NON viene inviato!
  value   = il valore inviato (o il valore iniziale)


GET o POST?
-----------
  GET   -> i dati si vedono nell'URL:  pagina.php?nome=Luca&eta=17
           in PHP:  $_GET["nome"]
  POST  -> i dati non si vedono nell'URL
           in PHP:  $_POST["nome"]
  $_REQUEST["nome"] funziona in tutti e due i casi.


I CAMPI
-------
TESTO / NUMERO / PASSWORD / AREA DI TESTO
  <input type="text" name="cognome">
  <input type="number" name="eta" min="1" max="99" value="18">
  <input type="password" name="pwd">
  <textarea name="note" rows="4" cols="40"></textarea>

  ATTENZIONE: arrivano SEMPRE come stringhe.
  Per fare i conti:  settype($eta, "integer");

RADIO (una sola scelta): stesso name, value diversi
  <input type="radio" name="classe" value="5A"> 5A
  <input type="radio" name="classe" value="5B" checked> 5B
  -> $_GET["classe"] vale "5B"

CHECKBOX (piu' scelte): name con le QUADRE []
  <input type="checkbox" name="tab[]" value="2"> Tabellina del 2
  <input type="checkbox" name="tab[]" value="5"> Tabellina del 5
  -> $_GET["tab"] e' un array:  $_GET["tab"][0] = "2", $_GET["tab"][1] = "5"
  ATTENZIONE: se non spunti niente, $_GET["tab"] NON ESISTE -> isset

SELECT (menu a tendina)
  <select name="squadra">
      <option value="Inter">Inter</option>
      <option value="Milan">Milan</option>
  </select>
  -> $_GET["squadra"] = il value scelto

  Select generata da PHP con un for (da un array $nomi):
    echo "<select name='squadra'>";
    for ($i = 0; $i < count($nomi); $i++)
        echo "<option value='" . $nomi[$i] . "'>" . $nomi[$i] . "</option>";
    echo "</select>";

HIDDEN (nascosto)
  <input type="hidden" name="saldo" value="100">
  Serve a PORTARSI DIETRO un dato da una pagina all'altra
  (il PHP non ricorda niente tra un invio e l'altro).
  Si vede nel sorgente della pagina (Ctrl+U).

IMAGE (immagine cliccabile) - esercizio tabellina2 del prof
  <input type="image" src="tabelline2.jpg" name="tab">
  Invia il form e manda dove hai cliccato: $_GET["tab_x"], $_GET["tab_y"]

PULSANTI
  <input type="submit" value="Invia">     invia
  <input type="reset"  value="Cancella">  svuota il form
  <button>Calcola</button>                dentro un form = invia

ATTRIBUTI UTILI
  required     il campo e' obbligatorio
  min / max    limiti di un campo number
  maxlength    lunghezza massima di un testo
  checked      radio/checkbox gia' selezionato


NOMI CON LE QUADRE -> ARRAY IN PHP
----------------------------------
  name="ris[]" (ripetuto)          -> $_GET["ris"][0], [1], [2]...
  name="ris[0]", name="ris[1]"     -> $_GET["ris"][0], $_GET["ris"][1]
  scorrerli:
    $ris = $_GET["ris"];
    for ($i = 0; $i < count($ris); $i++)
        echo $ris[$i] . "<br>";


VEDERE COSA ARRIVA (debug)
--------------------------
  Con GET guarda l'URL nella barra del browser.
  Oppure stampa il campo:  echo $_GET["nome"];
