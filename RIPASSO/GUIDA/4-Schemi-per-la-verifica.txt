# 4 – Schemi per la verifica ⭐

Quasi tutte le verifiche "stile SquadreCalcio" si risolvono **combinando questi pezzi**.
Impara gli schemi, poi cambi solo i nomi delle variabili.

---

## Schema A – Leggere il file riga per riga
File `dati.txt`: `Inter,Milan,2,0`
```php
$righe = file("dati.txt");
for ($i = 0; $i < count($righe); $i++)
{
    $parti = explode(",", $righe[$i]);
    $casa   = $parti[0];
    $ospite = $parti[1];
    $gc     = $parti[2];
    $go     = $parti[3];
    settype($gc, "integer");     // numero
    settype($go, "integer");     // numero (toglie anche il \n finale)
    // ... qui uso i dati ...
}
```
⚠️ L'**ultimo** campo della riga ha il `\n` attaccato.
- se è un numero → `settype` lo toglie;
- se è un testo → usa `trim($parti[3])`.

⚠️ Niente righe vuote in fondo al file (darebbero errore).

---

## Schema B – Creare la casella e CONTARE (quante volte?)
"Quante partite ha giocato ogni squadra?"
```php
if (!isset($giocate[$casa])) $giocate[$casa] = 0;   // casella nuova = 0
$giocate[$casa] = $giocate[$casa] + 1;              // +1
```

## Schema C – SOMMARE (quanto in totale?)
"Quanti gol ha segnato ogni squadra?"
```php
if (!isset($gol[$casa])) $gol[$casa] = 0;
$gol[$casa] = $gol[$casa] + $gc;                    // + il valore
```

## Schema D – MEDIA
Servono **due** array: la somma e il conteggio.
```php
// nel ciclo:
if (!isset($somma[$nome])) { $somma[$nome] = 0; $num[$nome] = 0; }
$somma[$nome] = $somma[$nome] + $voto;
$num[$nome]   = $num[$nome] + 1;

// dopo il ciclo:
foreach ($somma as $nome => $s)
{
    $media = $s / $num[$nome];
    printf("%s: %.2f<br>", $nome, $media);
}
```

## Schema E – MASSIMO (chi ha di più? anche a pari merito)
Due giri: prima trovo il valore massimo, poi stampo **tutti** quelli che lo hanno.
```php
$max = -1;                                  // più piccolo di ogni valore possibile
foreach ($gol as $squadra => $g)
    if ($g > $max) $max = $g;

echo "Più gol ($max): ";
foreach ($gol as $squadra => $g)
    if ($g == $max) echo "$squadra ";
```
Per il **minimo**: parti da un numero enorme (`$min = 999999;`) e usa `<`.

## Schema F – CLASSIFICA (ordinare dal più alto)
```php
arsort($punti);                 // ordina i valori dal più grande, tiene i nomi
$pos = 1;
echo "<table border=1>";
foreach ($punti as $squadra => $p)
{
    echo "<tr><td>$pos</td><td>$squadra</td><td>$p</td></tr>";
    $pos++;
}
echo "</table>";
```

## Schema G – ELENCO in ordine alfabetico
```php
ksort($punti);                          // ordina per chiave (nome)
foreach ($punti as $squadra => $p) echo "$squadra<br>";
```

## Schema H – Salvare la riga intera (per cercarla dopo)
```php
// nel ciclo di lettura:
$partite[] = array($casa, $ospite, $gc, $go);

// dopo: tutte le partite di una squadra
for ($i = 0; $i < count($partite); $i++)
    if ($partite[$i][0] == $scelta || $partite[$i][1] == $scelta)
        echo $partite[$i][0]." - ".$partite[$i][1]." ".$partite[$i][2]."-".$partite[$i][3]."<br>";
```

## Schema J – Creare un file HTML in output
```php
$html = "<html><body><h1>Squadre</h1><ul>\n";
foreach ($punti as $squadra => $p)
    $html = $html . "<li>$squadra</li>\n";
$html = $html . "</ul></body></html>";
file_put_contents("squadre.html", $html);
echo "<a href='squadre.html'>Apri squadre.html</a>";
```

## Schema K – Test con domande da file (stile TestVeroFalso)
```php
// 1) mostro le domande
$righe = file("domande.txt");
echo "<form action='correggi.php' method='get'>";
for ($i = 0; $i < count($righe); $i++) {
    $parti = explode(";", $righe[$i]);
    echo $parti[0]."<br>";
    echo "<input type=radio name=ris[$i] value=V> V ";
    echo "<input type=radio name=ris[$i] value=F> F<br>";
}
echo "<input type=submit></form>";

// 2) correggi.php: rileggo il file e confronto
$ris = $_GET["ris"];
$giuste = 0;
for ($i = 0; $i < count($righe); $i++) {
    $parti = explode(";", $righe[$i]);
    if (isset($ris[$i]) && $ris[$i] == trim($parti[1])) $giuste++;
}
echo "Punteggio: ".round($giuste / count($righe) * 100)."/100";
```
Domande in ordine casuale senza ripetizioni: `array_rand` + `unset` (vedi Soluzione1 del prof).

## Checklist prima di consegnare
- [ ] `settype` sui numeri letti dal file, `trim` sull'ultimo campo se è testo
- [ ] `isset` prima di sommare in una casella nuova
- [ ] massimo/minimo: considerati i **pari merito**?
- [ ] classifica: `arsort` (non `sort`, che perde i nomi!)
- [ ] ordine alfabetico: `ksort` sulle chiavi oppure `sort` su un array di nomi
- [ ] il form ha `name` su ogni campo?
- [ ] `isset($_GET[...])` prima di leggere un dato del form
