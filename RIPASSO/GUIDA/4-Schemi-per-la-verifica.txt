E) ORDINARE A MANO (bubble sort)  -  classifica o ordine alfabetico
-------------------------------------------------------------------
Ordino l'elenco $nomi in base a $punti (dal piu' alto):
for ($i = 0; $i < count($nomi) - 1; $i++)
    for ($j = 0; $j < count($nomi) - 1 - $i; $j++)
        if ($punti[$nomi[$j]] < $punti[$nomi[$j + 1]])     // sono al contrario?
        {
            $tmp = $nomi[$j];                // scambio i due NOMI

            $nomi[$j + 1] = $tmp;
        }

I) STRINGA CARATTERE PER CARATTERE (controlli)
----------------------------------------------
$maiuscole = 0;  $cifre = 0;

{
    $c = substr($pwd, $i, 1);
    if ($c >= "A" && $c <= "Z") $maiuscole++;

K) NUMERI CON I CICLI
---------------------
divisibile:   if ($n % $d == 0)
cifre di un numero:   while ($n > 0) { $cifra = $n % 10;  $n = ($n - $cifra) / 10; }
binario:              while ($n > 0) { $bit = $n % 2;  $bin = $bit . $bin;  $n = ($n - $bit) / 2; }
primo:  conto i divisori da 1 a $n: e' primo se sono esattamente 2
