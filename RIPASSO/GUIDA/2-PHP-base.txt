VARIABILI
---------

PRINTF (come in C)
------------------
printf("%s ha %d punti<br>", $nome, $punti);   // %s testo, %d intero
printf("Media: %.2f", $media);                  // %.2f = 2 decimali
printf("%02d", 5);                              // "05" (2 cifre, zero davanti)
printf("%d%%", 50);                             // %% stampa il simbolo %

ARRAY CON CHIAVI-PAROLA  (il piu' importante!)
----------------------------------------------
Pensalo come un ARMADIETTO: ogni casella ha un'etichetta (la CHIAVE).
$punti["Inter"] = 3;
$punti["Milan"] = 0;
echo $punti["Inter"];        // 3

Prima di sommare, la casella deve esistere:
if (!isset($punti[$squadra])) $punti[$squadra] = 0;

COME SCORRERLO CON IL FOR?  Il for usa i numeri, non le parole.
Trucco: tengo anche un ARRAY NUMERATO con l'elenco dei nomi.
Lo riempio quando incontro un nome NUOVO (cioe' quando la casella non esiste):

if (!isset($punti[$squadra]))
{
    $punti[$squadra] = 0;      // casella nuova
    $nomi[] = $squadra;        // aggiungo il nome all'elenco
}

Poi per scorrere:
for ($i = 0; $i < count($nomi); $i++)
{
    $n = $nomi[$i];                   // il nome
    echo $n . ": " . $punti[$n] . "<br>";   // il suo valore
}
