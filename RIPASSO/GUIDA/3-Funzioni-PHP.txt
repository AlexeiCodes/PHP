3 - LE FUNZIONI CHE USIAMO
==========================

Solo queste. Tutto il resto si fa con for, if e array.

FILE
----
file("dati.txt")
    legge il file: ogni riga diventa un elemento di un array.
    ATTENZIONE: ogni riga ha l'a capo \n attaccato alla fine.
    $righe = file("squadre.txt");
    $righe[0]  ->  "Inter,Milan,2,0\n"

STRINGHE
--------
explode(separatore, stringa)
    spezza la stringa in un array
    explode(",", "Inter,Milan,2,0")  ->  ["Inter", "Milan", "2", "0"]
    explode(":", "08:15")            ->  ["08", "15"]

strlen(stringa)
    quanti caratteri
    strlen("ciao")  ->  4

substr(stringa, inizio, quanti)
    un pezzo di stringa (si parte da 0)
    substr("Buongiorno", 0, 4)  ->  "Buon"
    substr("Buongiorno", 4, 1)  ->  "g"      (UN carattere)
    substr("ciao", -1, 1)       ->  "o"      (l'ultimo)

strtoupper(stringa)
    tutto maiuscolo
    strtoupper("Rossi")  ->  "ROSSI"
    Serve per confrontare senza badare a maiuscole/minuscole:
    if (strtoupper($a) == strtoupper($b)) ...

    (Per sapere se UN carattere e' una lettera maiuscola o una cifra
     non serve nessuna funzione, si confronta e basta:
        if ($c >= "A" && $c <= "Z")   maiuscola
        if ($c >= "a" && $c <= "z")   minuscola
        if ($c >= "0" && $c <= "9")   cifra          )

trim(stringa)
    toglie spazi e \n all'inizio e alla fine
    trim("Roma\n")  ->  "Roma"
    Da usare sull'ULTIMO campo di una riga quando e' un TESTO.

NUMERI
------
settype($x, "integer")
    trasforma in intero (e toglie anche il \n finale)
    "2\n"  ->  2
settype($x, "double")
    trasforma in decimale
    "10.21\n"  ->  10.21

ARRAY
-----
count($a)
    quanti elementi ha l'array

isset($x)
    esiste?  (la variabile, la casella dell'array, il campo del form)
    isset($punti["Inter"])     la casella "Inter" esiste?
    isset($_GET["nome"])       il form ha inviato "nome"?

STAMPA
------
echo        stampa
printf      stampa formattata (%d intero, %s testo, %.2f decimali, %02d)
